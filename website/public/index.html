What is reverse engineering?

Finding out how software works by examining the program.

To explain this, an analyst identifies the input, follows the caller and reads the values at those addresses.

Do I need to read assembly to get started?

No.

This function converts a brick’s horizontal position into a left/right sound value.

At the initial scale of 1, the screen center produces zero. Positions to the left produce negative values; positions to the right produce positive values.

Case study · Native

Rebuilding DX-Ball

DX-Ball is a 1996 Windows game. The project is reconstructing it in C, using REA to inspect the executable and independent tests to check the recovered behavior.

Follow the investigation

Work so far covers boards, resources, brick hits, animations, particles and bonus production. The playable game is still in progress.
